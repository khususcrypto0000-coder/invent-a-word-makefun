Entry for the make.fun bounty **"Invent a Word We Need"** — one brand-new English word for a gap everybody knows but nobody has named.

**The word: `nodbluff`** — nodding along to a conversation you stopped understanding minutes ago.

`nod` + `bluff`: you keep nodding so nobody notices you lost the thread five minutes ago. Sayable, spellable, memorable — and instantly recognizable the first time you hear it.

## Run it

```bash
python3 main.py
```

This writes the entry (one line, 85 characters) to `/output/entry.txt` and verifies the file is byte-identical to the entry.
